# E-Learning Landing Page

## About The Project
A modern e-learning website landing page implemented based on a Figma design. This project focuses on translating a visual design into a structured and responsive web interface.

## Built With
- HTML5
- CSS3
- Bootstrap

## Features
- Navigation bar with course-related links
- Hero section with call-to-action buttons
- Featured courses section
- Modern typography and visual styling
- Responsive layout (if supported by the implementation)

## What I Learned
- Translating a Figma design into a webpage
- Building layouts with HTML and CSS
- Using Bootstrap components and layout utilities
- Improving front-end styling skills

## Project Purpose
This project was created for practice as part of my front-end web development learning journey.
